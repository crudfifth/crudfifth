<summary>Regenerate or preview this profile</summary>

Requires Node.js 22 or newer. No additional packages are needed. Run these commands from the repository root:

```sh
node collect.mjs
node render.mjs
npm test
npm run serve
```

The first command collects a fresh public snapshot; the second renders both SVG themes. Open `http://127.0.0.1:4318` to preview the transparent images on dark or light backgrounds and check their still state. Updates are manual.
